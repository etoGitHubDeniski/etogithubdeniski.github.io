Данные, раскладка и шаблоны хранятся отдельно для каждого типа отчёта.
Шаблон и оформление
Стр. — номер строки (блоки с одной строкой встают рядом), Поз. — порядок внутри строки, Шир. — ширина в % от строки. Выс. — вес высоты для строк с графиками: они делят между собой место, оставшееся после таблиц и показателей (0 = высота по содержимому). Обрезки нет: высота строк подстраивается под контент.
Шаблон хранит тему, раскладку, набор блоков и категорий — но не данные. Можно завести отдельные шаблоны под ИВН, ОСП и КРУ.

Импорт / экспорт данных
Excel (.xlsx) требует интернет при первом использовании; CSV работает всегда. Все изменения автосохраняются в браузере.
PDF: в диалоге печати выберите «Сохранить как PDF», поля — «Нет», масштаб — 100%, фоновая графика — включена.
