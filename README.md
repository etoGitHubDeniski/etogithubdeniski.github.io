# Генератор еженедельных отчётов

Локальное приложение без сборки и зависимостей: открыть `index.html` в браузере.

## Структура

```
report-generator/
├── index.html              разметка: панель редактора + предпросмотр листа
├── README.md
└── assets/
    ├── css/style.css       стили интерфейса и листа отчёта
    ├── img/                логотипы, попадают в шапку отчёта
    │   ├── logo-left.png
    │   └── logo-right.png
    └── js/
        ├── config.js       справочники: типы отчётов, категории, блоки, темы, раскладка по умолчанию
        ├── state.js        состояние: демо-данные, хранилище, переключение типов, расчёты
        ├── charts.js       отрисовка графиков в SVG
        ├── render.js       сборка листа отчёта, автоподгонка под формат
        ├── editor.js       левая панель: формы, таблицы, раскладка, шаблоны
        ├── io.js           импорт и экспорт: JSON, CSV, Excel
        └── main.js         точка входа
```

Скрипты подключаются обычными тегами `<script>` по порядку (без модулей) —
так страница работает при открытии файла напрямую, без локального сервера.
Каждый файл добавляет свои функции в глобальную область; порядок подключения
важен: `config` → `state` → `charts` → `render` → `editor` → `io` → `main`.

## Как пользоваться

1. Выбрать тип отчёта вверху панели: ИВН, ОСП, КРУ Самосвалы, КРУ Экскаваторы.
2. Заполнить период и данные (вручную, импортом CSV/Excel или загрузкой JSON).
3. При необходимости поправить оформление: тема, плотность, раскладка блоков.
4. Кнопка **Скачать PDF** → в диалоге печати выбрать «Сохранить как PDF»,
   поля «Нет», масштаб 100%, фоновая графика включена.

## Данные и хранение

- Данные каждого типа отчёта хранятся в браузере отдельно и не мешают друг другу.
  Если хранилище недоступно, приложение работает, но не запоминает состояние между сессиями.
- Формат `35 (15)` в отчётах ОСП и КРУ означает «всего (передано/верифицировано)»;
  итоги считаются по обеим цифрам.
- Итог строки считается автоматически; введённое вручную значение имеет приоритет
  и подсвечивается в редакторе.
- Шаблон (тема, раскладка, состав блоков) сохраняется и экспортируется отдельно от данных.

## Что дальше
